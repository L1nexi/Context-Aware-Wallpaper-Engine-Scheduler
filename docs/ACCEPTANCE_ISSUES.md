## 开放问题

### A-01 天气运行状态缺少连贯的可观测性

- 状态：现有能力暂时够用；新增健康状态留待后续小版本。
- 观察：导出的约 10 分钟、622 个 Tick 均显示天气不可用；同一时段运行日志有天气失败提示，Event Log 没有天气异常或恢复事件。仅看现有记录，不容易把天气状态与 Profile 更新对应起来。
- 期望：关键边界有可开启且脱敏的 DEBUG 日志；打开设置页面即可看到**当前已生效配置**的天气运行状态，无需先进入天气步骤，并知道如何自己尝试排查。运行日志、Event Log 和设置页面对失败及恢复使用可对照的信息。持续失败门槛按真实抓取或持续时间判断，不按 Tick 数判断。
- 进展（2026-09-24）：天气抓取、Profile 天气校验与应用阶段已补安全的 WARNING／DEBUG 日志，可通过 `WESCHEDULER_LOG_LEVEL=DEBUG` 开启调试记录。设置页健康状态与 Event Log 状态变化仍待处理。
- 待明确：健康状态的分类、门槛、恢复条件和各记录载体的职责。当前天气抓取间隔为 600 秒。

### A-02 天气告警与修改操作的关联不明确

- 状态：留待后续小版本，在可复现时核实关联。
- 观察：用户曾尝试把天气 API Key 改错，随后在日志中看到 Sensor 的天气抓取告警；检查 `profile.json` 时，Key 仍是正确值。用户不确定这次修改是否影响运行，也不知道告警是否由它引起。日志中另有多条“Applied Profile update”，但目前无法把它们与具体操作对应。
- 待核对：设置接口当时的响应、Profile 提交时间，以及告警属于凭据拒绝还是连接故障。不得从告警直接推断错误 Key 已提交；复现时不得在日志中输出 Key。
- 进展（2026-09-24）：新的 Profile 应用日志会标明天气设置是否发生变化；这不能倒推出上次手工操作的结果。

### A-03 草稿天气凭据缺少手动校验

- 状态：已实现，待桌面验收。
- 观察：输入 API Key 后没有可主动点击的校验入口；界面只提示“保存时会进行一次校验”。
- 期望：设置页允许用户主动校验当前草稿的 Key，并明确区分这个结果和 A-01 的运行状态；同一 Key 的成功测试不因后续临时连接故障失效，连接暂不可用时可由用户确认后保存。
- 进展（2026-09-25）：天气页及配置草稿页均可测试当前 Key；成功记录只适用于同一 Key。保存默认仍联网校验天气设置；已测试通过的 Key 可直接保存，临时连接故障或配额限制可确认后保存。服务明确拒绝无效 Key 时仍提示修正。需在真实网络和原生窗口下复核。

### A-04 天气校验失败提示不够明确

- 状态：部分完成。
- 观察：用户无法从提示中清楚区分网络连接问题、API Key 被拒绝和其他天气服务错误。
- 期望：按实际可判别的失败类型给出相应提示及用户可尝试的下一步；未知原因不猜测为 Key 错误。DEBUG 日志应保留足以定位失败阶段的信息，同时不记录凭据。
- 进展（2026-09-25）：后端日志已区分凭据拒绝、超时、代理、连接、响应格式和 HTTP 状态；接口向界面返回安全的原因码，界面提供分类提示。无效 Key 文案已改为“无效的 API Key。”，不推测激活时间。待用户复核其余措辞与真实网络表现。

### A-05 获取天气 API Key 的指引不足

- 状态：已实现首版，待用户审阅截图。
- 观察：当前界面虽有获取 Key 的链接，但缺少足够清楚的申请、启用及填写步骤说明。
- 进展（2026-09-24）：天气页改为“注册账号 → 点击 Generate 生成 API Key → 确认 Status 为 Active → 粘贴并测试”的指引，保留官方页面入口。用户计划补截图；步骤和截图位置待审。

### A-06 城市估算在部分网络环境返回 503

- 状态：部分完成，待目标网络复核。
- 观察：裸连和系统代理时自动定位失败，使用虚拟网卡时可用；手工填写地点正常。服务端返回 `POST /api/location-estimates` 的 503。
- 待核对：目标网络环境下的可用性、DEBUG 日志能否区分失败阶段，以及界面是否明确提示可手填和其他自助排查步骤；手填路径应继续可用。
- 进展（2026-09-24）：自动定位失败时已记录不含 IP 的失败类别与 HTTP 状态；界面给出分类原因和手填路径。目标网络复核仍待进行。

### A-07 播单数量缺少单位说明

- 状态：已实现，待桌面验收。
- 观察：扫描成功后，选项近似显示为“CASUAL_ANIME 60”，用户难以判断 `60` 表示什么。
- 期望：明确它是播单中的壁纸数量。
- 进展（2026-09-24）：扫描结果拆为 Wallpaper Engine 中的播放列表名称、壁纸数量两列，并加入英文名兼容性建议；场景绑定的播单选项也补上“张壁纸”单位。扫描结果现使用有表头的表格，仍待桌面验收。

### A-08 首次场景绑定缺少建议默认项

- 状态：已按用户建议实现，待桌面验收。

- 进展（2026-09-24）：仅首次设置预选上述五项，但不自动猜测播单；每项需显式绑定后才能继续，用户也可取消预选项。已有 Profile 不受影响。按最新反馈移除了场景旁的“推荐”小字。
